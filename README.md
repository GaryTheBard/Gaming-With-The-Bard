# Gaming With The Bard

Starter website for the **Gaming With The Bard** brand and YouTube companion.

## Current scope

This repo currently includes a lightweight static site skeleton so you can quickly iterate on:

- Video game reviews
- Gaming news and release information
- Guides and strategy write-ups
- Featured YouTube channel content

## Project structure

- `index.html` - Landing page and basic content sections
- `styles.css` - Base styling/theme
- `script.js` - Small behavior for dynamic year in footer

## Quick start

Open `index.html` in a browser to preview the starter site.
